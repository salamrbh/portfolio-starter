# Portfolio Starter

A minimal portfolio website to build on. You need [Node.js](https://nodejs.org) 24 or newer.

1. **Install**

   ```bash
   npm install
   ```

2. **Start**

   ```bash
   npm start
   ```

3. **Open in the browser**

   Go to [http://localhost:4321](http://localhost:4321). If the browser did not open by itself, copy this address into it.
